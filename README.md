# SeatBook Application

A React Native and Expo mobile application for interactive seat booking, complete with booking history management, filtering options, and revenue calculation.

## 🚀 Features
* Interactive seat selection interface.
* Date automation and selection helpers.
* Booking history dashboard with filters for custom dates and service types (regular/express).
* Automated total revenue calculation based on filtered data.

## ⚙️ Installation (Local Setup)

Follow these steps to clone and set up the repository locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Asterithon/seatbookingapp.git
   
2. **Navigate to the project directory:**
   cd seatbook

3. **Install dependencies:**
   npm install

## ▶️ How to Run the App
Once the installation is complete, you can run the application using Expo:

1. **Start the development server:**
   npx expo start

2. **Open on your device or emulator:**
* Install the Expo Go app on your Android or iOS device.
* Scan the QR code displayed in your terminal using your camera (Android) or the Expo Go app (iOS).
* Alternatively, press a in the terminal to open it on an Android emulator.
